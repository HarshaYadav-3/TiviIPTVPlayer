## 🔧 Troubleshooting Common Issues

### "My playlist won’t load."
- Make sure your M3U/M3U8 file is valid. Try opening it with a text editor to see if it has content.
- Check that the URLs in the playlist are accessible. Some providers limit streaming to certain devices or locations.

### "The app is slow or laggy."
- Close other heavy applications that might be using your internet connection.
- Try lowering the video quality in the settings.
- Restart the app—sometimes a quick refresh solves temporary glitches.

### "No sound is playing."
- Check your system volume and make sure the app isn’t muted (press M if you aren’t sure).
- Try a different channel to see if the issue is specific to one stream.

### "The guide is empty."
- Your playlist may not include EPG data. Check with your IPTV provider to see if they offer an EPG URL.
- You can manually enter an EPG URL in the settings if you have one.
